## 这版有什么

- 模型与技能统一编号，首选卡、两个备选和图标角标使用同一个排名结果。
- 根据自己的模型、已有技能、选取席位和游戏内几号位重新计算；再次识别后排除已选项及不合法候选。
- 敌方已有半套组合时保留提醒，显示已有与缺少的组件；样本充分且自身收益接近最优时才让截胡改变首选。
- 中文技能／模型名称、更明显的前十角标；组合面板可隐藏、可按历史胜率浏览。
- 独立配置与数据库目录：`%APPDATA%\ability-draft-plus-cn-beta`。首次默认简体中文，更新源指向本分支的 Beta 渠道。

内置 **2026-10-10（7.41f）公开 Windrun 快照**：513 个技能、127 个模型、5,434 条技能组合、3,820 条模型＋技能组合。无个人对局或账号设置；不内置三技能组合及分路位移统计，需要成功联网更新后补齐。快照可供离线使用，不代表最新补丁数据。

## English

A Windows x64 community Beta of **Tiarin Hino's Ability Draft Plus**, focusing on Chinese terminology and one contextual ranking for models and abilities. This is not an official release from the upstream author, Windrun or Valve.

- One top-pick card, two alternatives and numbered badges share the same recommendation.
- Advice updates using your model, drafted skills, draft seat and role preference. Rescanning removes picked and illegal choices.
- Enemy half-combos remain visible. Denial can affect the first recommendation only with adequate evidence and near-optimal personal value.
- Separate profile: `%APPDATA%\ability-draft-plus-cn-beta`; Simplified Chinese by default; updates target this fork's Beta channel.

The bundled **2026-10-10 / patch 7.41f public Windrun snapshot** contains 513 abilities, 127 models, 5,434 ability pairs and 3,820 model/ability pairs, without personal matches or account settings. Triplets and role-shift statistics require an online refresh. The snapshot supports offline use but is not automatically current-patch data.

Download the installer or portable `.exe` from Assets. The portable executable also uses the separate application-data directory. **The packaged app starts successfully with a fresh profile; type checks, 1,125 unit tests and 2 end-to-end tests passed.** An actual installer-driven installation was not tested. Release executables are unsigned, so Windows may report an unknown publisher.

If online refresh opens a Windrun verification window, complete the check yourself, keep the window open, and click **Retry data update after verification** in the app. This recovery has **not yet been verified end to end against a real human-verification challenge**. Refresh availability is not guaranteed on all networks; existing statistics remain available on failure. No credentials for the original author's private services are included, so dependent features may be unavailable.

The ranking is **experimental heuristic advice, not a match-win prediction or a proven win-rate improvement**. The public demo uses synthetic inputs. New recommendation text currently prioritizes Chinese.
